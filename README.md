# 🎬 Video Extractor PRO

Desktop application built with Python to extract data from YouTube videos and save it into an Excel file.

## 🚀 Features

✅ Extract video data (title, duration, channel, date, views)  
✅ Export to Excel automatically  
✅ GUI with Tkinter  
✅ Search videos  
✅ Delete entries  
✅ Open video directly in browser  
✅ View full description  
✅ Thumbnail preview  

## 🖥️ UI

- Input URL
- Table view (like Excel)
- Double-click for details

## 📦 Tech Stack

- Python
- Tkinter
- Pandas
- OpenPyXL
- yt-dlp

```bash
pip install -r requirements.txt
